## Descripción del proyecto 📋

El proyecto integrador **Hospital San Rafael** es un sistema orientado a la gestión hospitalaria, desarrollado con el propósito de optimizar procesos de practicas universitarias dentro de las instalaciones.

El sistema permite administrar módulos relacionados con usuarios, autenticación, control de acceso y manejo de la información con respecto a los horarios y fechas de las practicas.

---

## Objetivos 🎯

- Facilitar la gestión de información para practicas hospitalarias.
- Implementar un sistema seguro de autenticación.
- Mejorar la organización de los procesos administrativos.

---

## Tecnologías utilizadas 🛠️
- SQL
- PostgreSQL  
- Java

---

## Características principales ✨

- Inicio de sesión seguro.
- Gestión de usuarios (practicantes, administrativos y docentes).
- Interfaz intuitiva y organizada.
- Conexión con base de datos PostgreSQL.
- Estructura modular para futuras mejoras.
